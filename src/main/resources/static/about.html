About CareerCraft AI

CareerCraft AI is a career assistant for job seekers. It was built by Manasvi Sawant, and the concept comes from her Google Cloud Gen AI Academy (APAC Edition) project. The aim is simple: replace the five-plus separate tools a job seeker juggles with one assistant that turns generic advice into application-ready material.

How it was built

This version is a Java web application, built as a mini project for the Advanced Java Programming Lab course (Savitribai Phule Pune University). It uses Spring Boot, Hibernate, and MySQL.
